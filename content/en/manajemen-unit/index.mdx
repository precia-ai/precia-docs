# Unit List

The **Units** page lists every clinical unit (department) in your organization, such as Cardiology, Radiology, or Emergency. From here you can check each unit's status, search for a specific unit, filter by status, and open a unit's details to manage it further.

## 1. Opening the Units page

Click **Units** in the left sidebar. This page shows all units as cards in a grid, rather than a table, making it easier to browse.

![Units page showing summary cards, a search box, status filter, and the grid of unit cards](/screenshots/en/manajemen-unit/index/01-daftar-unit.png)

The top of the page shows four summary cards:

- **Total**: the total number of units registered in the organization.
- **Active**: the number of units with active status, meaning the unit is fully operational and can process transactions.
- **Pilot**: the number of units still in the pilot/trial stage.
- **Inactive**: the number of units whose status has been disabled.

The **Register Unit** button (blue box, top right) is used to create a new clinical unit. See the separate "Registering a New Unit" guide for the full steps.

## 2. Searching for a specific unit

Use the search box (blue box, left side) to find a unit by unit name, unit code, or service type. Type a keyword and the card list below filters automatically as you type, no button press needed.

![Search results for the keyword "cardio", showing only one matching unit card](/screenshots/en/manajemen-unit/index/03-pencarian.png)

In the example above, typing "cardio" immediately narrows the list to one matching unit (Cardiology). The caption above the card grid ("X of Y units shown") updates to match the search result. Click the **×** icon at the right edge of the search box to clear the keyword and show all units again.

## 3. Filtering by status

Next to the search box are four status filter pills (blue box): **All**, **Active**, **Pilot**, and **Inactive**. Each pill shows the count of units in that status next to its label. Click a pill to show only units with that status.

![The "Pilot" status filter selected, showing a message that no units match because no unit is currently in pilot status](/screenshots/en/manajemen-unit/index/02-filter-status.png)

The currently selected pill is highlighted in solid blue. If no unit matches the selected status (as in the example above, where the **Pilot** filter is selected but no unit is in pilot status yet), the page shows the message "Unit not found. Adjust your search or register a new unit." Click the **All** pill again to show every unit.

Search and status filters can be combined. For example, typing a keyword while the **Active** status filter is selected shows only active units that also match that keyword.

## 4. Reading a unit card

Each unit card in the grid shows the following summary information:

- **Unit name** and **unit code** (a short code, e.g. "CARD" for Cardiology).
- A **status badge** in the top-right corner of the card (Active/Pilot/Inactive).
- **Service**: the unit's clinical service type.
- **Updated**: the date this unit's data was last changed.
- A **Manage unit** link at the bottom of the card.

## 5. Opening a unit's details

Click anywhere on a unit card (or the **Manage unit** link) to open that unit's detail page. There you can edit the unit's data, manage unit members, enable or disable AI modules for that unit, and view its change history. See the separate "Unit Details" and "Managing Unit Members" guides for the full steps.
